# 생명과학실험2 온라인 실습

충남대학교 생명시스템과학대학 · 생명과학실험2

노트북과 브라우저만 있으면 되는 실습 도구를 주차별로 모아 둔 곳입니다. 설치하거나 가입할 것은 없고, 모든 계산은 브라우저 안에서만 이루어집니다.

**사이트**: https://jw-huh.github.io/biology-lab-online/

### 10주차 · 프라이머 설계

| 순서 | 도구 | 하는 일 |
|---|---|---|
| 1 | 유전자 핀볼 | 학번을 넣어 오늘 설계할 유전자의 mRNA와 gDNA를 받는다 |
| 2 | 엑손 찾기 | mRNA와 gDNA를 맞대어 엑손·인트론 경계를 찾는다 |
| 3 | 역상보 · Tm 계산기 · 서열 뷰어 | Reverse 프라이머를 만들고 Tm과 결합 위치를 맞춘다 |
| 4 | 프라이머 점검 | 반복 서열, 머리핀, 이합체, 회문을 확인한다 |
| 5 | PCR 시뮬레이션 | 프로그램을 정해 돌리고 젤·증폭 곡선·Tm 곡선을 본다 |
| 6 | 비교평가 | 확정한 뒤 컴퓨터가 설계한 쌍과 견준다 |

### 11주차 · 도메인 교환 클로닝

| 순서 | 도구 | 하는 일 |
|---|---|---|
| 1 | 플라스미드 뷰어 | pUC19 지도, 서열 확대 보기, 제한효소의 절단 모양 |
| 2 | 도메인 지도 | 막단백질의 세 부분, 두 수용체 설명, 코돈 정렬 서열 |
| 3 | 설계 및 1차 PCR | 범위 정하기 → 프라이머 네 개 → PCR → 드래그로 젤 추출 |
| 4 | 연결 PCR 프라이머 | 효소 자리 검사, 내부 자리·방향·말단·반응 온도 판정 |
| 5 | 연결 PCR | 프라이머 없이 이어 붙이고, 같은 통에 바깥 프라이머로 증폭 |
| 6 | 클로닝 과정 | 벡터 자르기부터 형질전환·선별까지 단계별 애니메이션 |

**TLR5의 세포바깥 부분**과 **CD3 제타의 막관통 + 세포질 부분**을 이어 붙인 키메라 수용체 유전자를 pUC19에 넣습니다. 받는 신호는 TLR5 그대로이고 전달되는 신호만 CD3 제타로 바뀌는 설계입니다.

쓰는 서열은 TLR5 `NM_003268.6` (CDS 608..3184), CD247 `NM_198053.3` (CDS 65..559), pUC19 `L09137.2`입니다. 도메인 경계는 UniProt (O60602, P20963)의 막관통 영역 표기를 따랐습니다.

## 설계 원칙

어디서 끊을지, 프라이머를 어떻게 잡을지, 어느 효소를 쓸지는 **학생이 직접 정합니다.** 도구는 답을 미리 주지 않고 무엇이 문제인지만 알려 주며, 몇 번 막히면 그때 더 또렷한 힌트를 냅니다. 정답 값과 단계별 함정은 `instructor/` 메모에 있고, 이 폴더는 저장소에 올라가지 않습니다.

## 파일

```
docs/
  index.html          주차를 고르는 표지
  week10/             10주차 사이트 (도구 + 안내문)
  week11/             11주차 사이트 (도구 + 안내문)
tools/
  build-guides.py     안내문 마크다운을 guides.js 에 내장
  오프라인_만들기.ps1   수업용 오프라인 사본 zip
data/                 pUC19 원본 서열
instructor/           정답과 운영 메모 (저장소에 올리지 않음)
```

`docs/` 폴더가 그대로 사이트입니다. 주차를 더할 때는 `docs/week12/` 처럼 폴더를 하나 만들고 표지에 카드를 추가하면 됩니다.

안내문 마크다운을 고친 뒤에는 `python tools/build-guides.py`를 돌립니다. `file://` 에서는 브라우저가 `fetch`를 막으므로 안내문을 `guides.js` 에 내장해 두기 때문입니다.
