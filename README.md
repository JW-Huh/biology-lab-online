## **[→ 실습 사이트 열기](https://jw-huh.github.io/biology-lab-online/)**

## 주차

### [10주차 · 프라이머 설계](docs/week10/)

유전자 하나를 받아 qPCR 프라이머 한 쌍을 직접 설계하고, PCR을 돌려 확인합니다.

핀볼 → 엑손 찾기 → 역상보·Tm·서열 뷰어 → 프라이머 점검 → PCR 시뮬레이션 → 비교평가

### [11주차 · 도메인 교환 클로닝](docs/week11/)

두 수용체의 조각을 바꿔 끼운 유전자를 설계해 플라스미드에 넣습니다.

플라스미드 → 도메인 지도 → 설계 및 1차 PCR → 연결 PCR 프라이머 → 연결 PCR → 클로닝

주차 제목을 누르면 그 주차의 **따라하기 안내문**이 열립니다. 기록지와 실습 사이트 링크도 그 안에 있습니다.

## 설계 원칙

어디서 끊을지, 프라이머를 어떻게 잡을지, 어느 효소를 쓸지는 **학생이 직접 정합니다.** 도구는 답을 미리 주지 않고 무엇이 문제인지만 알려 주며, 몇 번 막히면 그때 더 또렷한 힌트를 냅니다.

## 수업 약속

실습 시간에는 생성형 AI에게 프라이머 설계나 기록지 답을 맡기지 않습니다. 이 실습에서 배우는 것은 결과가 아니라 **왜 그 선택이 되는지를 따지는 과정**입니다.
